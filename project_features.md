# Bastion (Tab Manager) - Features

Bastion is a MERN stack application designed to organize browser tabs into a tree structure, allowing users to visually map out how their tabs relate to one another and keep track of their line of thought.

## Core Features
1. **Tree-Structured Tab Organization:** Tabs are organized with parent, child, and sibling relationships, preventing the typical "flat wall of tabs" problem.
2. **Folder Grouping:** Users can group related tabs into folders for better categorization.
3. **Drag-and-Drop Interface:** Easily rearrange the tree structure and move tabs around freely.
4. **Multiple Workspaces:** Create independent tab trees for different projects, research threads, or contexts.
5. **Browser Extension Integration:** A companion browser extension captures open tabs and syncs them seamlessly into the web interface.

## Tech Stack
- **Frontend:** React + CSS
- **Backend:** Node.js + Express
- **Database:** MongoDB
- **Browser Extension API:** Captures and syncs tabs

## Advanced Features (Stitch Integration)
6. **Command Center:** Global search accessible via Cmd+K or the search bar for quickly finding tabs and executing actions.
7. **Semantic Discovery (✨ AI):** AI-powered semantic search that understands the meaning and context behind your search queries.
8. **Smart Workspace:** A dashboard overview displaying recent activity and overall workspace statistics.
9. **Active Tabs:** A focused, distraction-free list of all currently open tabs across the active window.
10. **Archived Sessions:** A dedicated space for viewing tabs and sessions that have been closed to save memory.
11. **AI Clusters:** Automatically organizes open tabs into topic-based clusters for easier context switching.
12. **Handoff:** Seamlessly send active tabs between connected devices (e.g., iPhone to MacBook).
13. **Mind Map View:** A visual node-based representation of the tab tree to see relationships spatially.
